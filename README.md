# ระบบการจัดการคอนโด (Project Web Condo)

เว็บแอปพลิเคชันสำหรับบริหารงานในคอนโดมิเนียม ผู้อยู่อาศัยใช้ดูและชำระใบแจ้งหนี้ แจ้งซ่อม จองสิ่งอำนวยความสะดวก ติดตามพัสดุ และรับประกาศประชาสัมพันธ์ ส่วนผู้ดูแลระบบใช้จัดการข้อมูลผู้อยู่อาศัย ห้องชุด สัญญาเช่า พัสดุ ผู้มาติดต่อ และประกาศ รวมถึงตรวจสอบการชำระเงินและดูรายงานภาพรวม

## ผู้ใช้และระบบภายนอก

| ประเภท | ชื่อ | หน้าที่ในระบบ |
|---|---|---|
| ผู้ใช้ | **user** ผู้อยู่อาศัย | ดูและชำระใบแจ้งหนี้ แจ้งซ่อมและติดตามผล จองหรือยกเลิกการจองสิ่งอำนวยความสะดวก และรับการแจ้งเตือนจากระบบ |
| ผู้ใช้ | **admin** ผู้ดูแลระบบ | จัดการผู้อยู่อาศัย ห้องชุด สัญญาเช่า พัสดุ ผู้มาติดต่อ และประกาศ ตรวจสอบการชำระเงิน อัปเดตสถานะงานซ่อม และดูรายงานกับประวัติการเปลี่ยนแปลงข้อมูล |
| ภายนอก | **QR PromptPay** | ผู้ให้บริการรับชำระเงินเมื่อผู้อยู่อาศัยชำระใบแจ้งหนี้ |
| ภายนอก | **LINE API** | ช่องทางส่งการแจ้งเตือนจากระบบไปยังผู้ใช้ |

## กระบวนการหลัก (DFD Level 1)

| รหัส | กระบวนการ |
|---|---|
| 1.0 | จัดการใบแจ้งหนี้และการชำระเงิน |
| 2.0 | จัดการการจองสิ่งอำนวยความสะดวก |
| 3.0 | จัดการบัญชีผู้ใช้และผู้อยู่อาศัย |
| 4.0 | จัดการอาคารและห้องชุด |
| 5.0 | จัดการสัญญาเช่า |
| 6.0 | จัดการพัสดุ |
| 7.0 | จัดการประกาศประชาสัมพันธ์ |
| 8.0 | จัดทำรายงานและตรวจสอบประวัติ |
| 9.0 | จัดการแจ้งซ่อมและติดตามงานซ่อม |
| 10.0 | จัดการผู้มาติดต่อ |

## แหล่งเก็บข้อมูล

| รหัส | แหล่งเก็บข้อมูล |
|---|---|
| D1 | บัญชีผู้ใช้และผู้อยู่อาศัย |
| D2 | อาคาร ห้องชุด และสัญญาเช่า |
| D3 | ใบแจ้งหนี้ การชำระเงิน |
| D4 | การแจ้งซ่อม |
| D5 | พัสดุ |
| D6 | สิ่งอำนวยความสะดวกและการจองส่วนกลาง |
| D7 | ผู้มาติดต่อ |
| D8 | ประกาศประชาสัมพันธ์ |
| D9 | ประวัติการเปลี่ยนแปลงและการใช้งาน (Log) |
| D10 | มิเตอร์น้ำ–ไฟฟ้า |

## ไดอะแกรม

| ลำดับ | ไดอะแกรม | คำอธิบาย |
|---|---|---|
| 01 | Use Case Diagram | ผู้ใช้แต่ละกลุ่มทำอะไรกับระบบได้บ้าง |
| 02 | Context Diagram | ระบบทั้งระบบเป็นกระบวนการเดียว พร้อมข้อมูลที่ไหลเข้าออกกับ user และ admin |
| 03 | Functional Decomposition Diagram (Structure Chart) | แตกระบบออกเป็น 10 ฟังก์ชันหลักและฟังก์ชันย่อย |
| 04 | Data Flow Diagram Level 1 | กระบวนการหลัก 10 กระบวนการ กับแหล่งเก็บข้อมูล D1–D10 |
| 05 | Process 1.0 จัดการใบแจ้งหนี้และการชำระเงิน | DFD Level 2 ของกระบวนการ 1.0 |
| 06 | Process 3.0 จัดการบัญชีผู้ใช้และผู้อยู่อาศัย | DFD Level 2 ของกระบวนการ 3.0 |
| 07 | Process 4.0 จัดการอาคารและห้องชุด | DFD Level 2 ของกระบวนการ 4.0 |
